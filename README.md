FocusGuard

FocusGuard is an anti-procrastination productivity application designed to help users stay focused, manage their study or work sessions, and reduce distractions.

Features

- ⏱️ Focus Sessions — Create and manage focused work or study sessions.
- 🚫 Distraction Control — Helps users stay away from unnecessary distractions during focus time.
- 📊 Activity Monitoring — Tracks user activity during sessions.
- 🗓️ Task & Time Management — Organize activities and manage available time effectively.
- 🎯 Productivity Tracking — Monitor progress and build better productivity habits.
- 🖥️ User-Friendly Interface — Simple and intuitive interface designed for everyday use.

Technology Stack

- Java
- JavaFX
- Maven
- Java 21

Project Structure

The project is organized into separate components to keep the application maintainable and easy to develop.

- UI — User interface and application screens
- Core Logic — Productivity and focus-session functionality
- Task Management — Handles tasks and activities
- Monitoring — Tracks user activity during focus sessions

Getting Started

Prerequisites

Make sure you have the following installed:

- Java 21 or later
- IntelliJ IDEA or another Java IDE
- Maven

Running the Application

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Make sure Java 21 is configured as the project SDK.
4. Allow Maven to download the required dependencies.
5. Run the application using the configured Maven/JavaFX run configuration.

Purpose

FocusGuard was created to provide a practical solution for students and individuals who struggle with procrastination and maintaining concentration. The goal is to combine time management, activity monitoring, and distraction control into one productivity-focused application.
